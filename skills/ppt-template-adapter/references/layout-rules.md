# Layout Rules — 字号、间距、表格与图表规范（可解释、可复算）

## 字号阶梯（默认 ladder，可在 plan.json 覆盖）
| 元素 | 字号 | 备注 |
|---|---|---|
| 封面标题 | 36pt（超长自动降 4–6pt） | 支持 1–2 行 |
| 封面副标题 | 20pt | 作者 / 单位 / 场合 |
| 节标题页 | 30pt | 简洁章节号 + 标题 |
| 内容页标题 | 28pt（有效字符 >46 降 4pt，>70 降 6pt） | 一行主张式结论 |
| 正文 L0 / L1 / L2 | 18pt → 16pt → 14pt → **下限 13pt** | 支持 `**加粗导语**：解释`，缩进 0.4in/级，**禁 <12pt 硬塞** |
| 原生表格文字 | 13.5pt → 12.5pt → 11.5pt → 10.5pt | 按行数自适应；表头用模板 `accent1` 白字加粗，数字列右对齐 |
| 图注 / 表注 caption | 11.5pt 斜体居中 | 含 `Figure N / Table N` 与 `[source, p.X]` |

## 溢出估算与防重叠（build_deck / check_deck 闭环）
- 字符宽：CJK/全角 ≈ 1.0×字号；Latin/数字 ≈ 0.52×字号（pt）；估算前自动剔除 `**` 标记。
- 行数 = `ceil(文本宽 / 可用宽)`；可用宽 = 盒宽 − 0.4in×level − 24pt 内边距。
- 需要高 = `Σ(行数 × 字号 × 1.18) + 段间距 × (n−1)`；超过盒高 1.08 → `warning`，1.30 → `critical`。
- **2D 重叠检查**：`check_deck.py` 对每页可见内容框（文本有效高、表格、图片）两两求交集；重叠 > 0.12 sq.in 且占小框 > 22% 判 `critical`（>10% 判 `warning`）。

## 版心、图文与表格适配
- 左右边距 0.55in；标题底到内容区顶 0.14in；页底留 0.45in（给页脚/页码让位）。
- 双栏 / 双图 gutter = 0.30in；图片严格 **等比 contain-fit**（纵横比容差 ≤2.5%，`check_deck` 强制；有效显示分辨率 <80 DPI 告警）。
- 单图+要点在宽屏或双占位符版式下自动选 `side_by_side`（左 40% 要点 + 右 57% 全高大图），避免扁平挤压；宽幅单图或双图自动 `stacked`。
- 定量主结果表优先用**原生 PPTX 表格**（可编辑、矢量清晰、随模板 `accent1` 自动配色）；复杂多级合并表可贴 200 DPI 裁剪原图保零转写误差。

## 字体、颜色与导出一致性
- **不硬编码字体名**：继承模板 `majorFont` / `minorFont`（含 East Asian 字体）。
- 深色底板自动切换浅色图注与兜底文字，维持 ≥4.5:1 可读对比度。
- `export_render.py` 以 108 DPI 渲染预览并比对 `theme_fonts` 与 PDF 实际嵌入字体 `pdf_fonts_used`，如实记录任何字体替换或缺失字形。

## 批量一致性（check_deck 强制核验）
- 同版式标题占位符几何跨页一致（容差 0.05in）；无出界形状（容差 0.06in）；无 2D 重叠；无零尺寸占位符；无图片拉伸；每页均含讲稿与证据来源；输出 `inheritance_summary` 供第三方核验。

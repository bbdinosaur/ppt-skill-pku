# 可复用学术汇报蓝图与上台自审清单 / Reusable Audience Talk Blueprints

本文件沉淀四类高频学术汇报的可复用叙事骨架、视觉组件搭配与上台前 10 项自审标准，供人类研究者或 Agent 直接复用，不依赖特定论文或领域。

## 1. 四类受众标准叙事蓝图

### A. 答辩委员会 / 顶会正式报告（Defense / Conference，10–15 min，10–14 页）
- **开场策略（前 45s）**：直接点明研究缺口、核心创新机制与最强定量对照结论，避免教科书式宽泛背景。
- **推荐骨架**：
  1. `title`：标题 + 报告人/单位/场合（居中封面，不打主张条）
  2. `roadmap`（`steps` 3–4 站）：今天要说服评委的 3 条核心证据链（非目录搬运）
  3. `motivation`（`two_col` 或 `kpis`）：现有方案上限 vs 本文解决的真瓶颈（S2/S3）
  4. `method` ×2–3（`figure` 右图 / `steps` 流水线）：一页一个核心机制，用“因为 X 所以 Y”解释为何有效
  5. `setup` + `result` ×2–3（`figure` / booktabs `table` + `kpis`）：先放最强对照主结果（S1），再放关键消融或效率对比（`chart`）
  6. `limitation`（`two_col`）：左栏诚实边界与失效条件，右栏影响范围与缓解方向（S3，不辩护）
  7. `conclusion`（`kpis` + ≤3 条 takeaway）：与主结果口径完全一致
  8. `qa_backup`（自动双栏速查板，不计入正文时长）：覆盖机制 / 数据 / 对照 / 局限四维追问
- **优先裁剪**：长篇 Related Work 列表、无对比价值的次要超参细节。

### B. 课题组会 / 同方向同行（Lab Meeting，12–20 min，10–14 页）
- **开场策略**：跳过领域常识，30 秒直切具体技术瓶颈与设计直觉。
- **重点倾斜**：方法机制与实现细节（~40%）+ 诊断性消融/反直觉误差分析（~35%）+ 失败案例与待讨论问题（~15%）。
- **推荐组件**：算法流程 `steps`、误差拆解 `table`/`chart`、失败边界 `two_col`、结论后接“开放讨论与下一步实验”。

### C. 跨组合作 / 跨学科交流（Cross-Group Collaboration，6–10 min，6–9 页）
- **开场策略**：先对齐共同关心的下游痛点与输入输出接口，再讲核心直觉与代价-收益权衡。
- **重点倾斜**：非本方向可懂的问题定义与术语翻译（~25%）+ 直观方法框图（~25%）+ 实用性能/成本对照（~30%）+ 合作接口与风险边界（~15%）。
- **优先裁剪**：密集公式推导、仅本子方向关心的次级榜单细节。

### D. 导师 / 管理层进度汇报（Progress Review，5–8 min，6–8 页）
- **开场策略**：先亮里程碑状态（已完成 vs 阻塞项）、较上次汇报的关键指标增量及本次需拍板事项。
- **重点倾斜**：阶段核心指标（`kpis` + `table`，~35%）+ 风险/阻塞根因与缓解排期（`two_col` + `progress`，~35%），大幅压缩已共识背景（≤10%）。

## 2. 上台前 10 项独立复核清单（Pre-Stage Self-Audit）
1. **源事实唯一**：全稿数字、图表与结论 100% 源自实际输入文件，未依据错误领域标签补造数据。
2. **一页一主张**：每张内容页有且仅有一句可讲 takeaway（≤30 中文字 / ≤18 英文词），且不与标题同义重复。
3. **动词配强度**：S1（定量+对照）用“提升/优于”，S2（定量无对照）用“表明/观察到”，S3（定性/局限）仅用“提示/待验证”。
4. **证据全闭合**：每张内容页底部标注精确物理定位（`Fig.N` / `Table N` / `§X.Y` / `p.N` / `Slide N`），零悬空引用。
5. **非目录叙事**：按“缺口 → 洞见/机制 → 主证据 → 机理分析 → 边界 → 结论”推进，非论文分节搬运。
6. **视觉无文字墙**：正文页灵活组合 `figure` / booktabs `table` / `chart` / `steps` / `kpis` / `two_col`，无连续三页纯 bullets。
7. **模板与旧稿合规**：尊重母版字体、配色、深浅底与页眉/页脚/Logo 安全框；编辑旧稿不覆盖保留原图并输出 `starting_deck_diff`。
8. **口语讲稿真可讲**：讲稿不照抄 bullets，含“为何重要 + 如何读图/表 + 尾句过渡”，总口播时长匹配预算（45–120s/内容页）。
9. **四维问答闭环**：`qa_prep` 覆盖机制 / 数据 / 对照 / 局限四类追问，答案数值与正文/源材料同口径并绑定 `cite_slide` 与 `backup_slide`。
10. **取舍透明可复核**：`tradeoffs`、`source_coverage_audit`（含图表与章节覆盖）、`uncertainty` 与渲染预览 PNG 齐备，他人可独立复核。

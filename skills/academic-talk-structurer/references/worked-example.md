- **记录进 `tradeoffs[]` 的可复核取舍**：
  1. 压缩 §2 相关工作至 P2 动机对比栏（省出 1 页给 Table 1 主对照与 Fig.2 消融）。

## 4. 四维追问速查样例（`qa_prep`）
- **`mechanism`**：为什么选择输入熵而非梯度幅值作门控信号？→ 推理期无反向梯度，单层熵计算仅占 0.8ms（`§3.2, p.3`），引 P3，备用 P7。
- **`data`**：2.38× 加速是在什么批次与硬件下测得？→ 统一在单卡 Jetson Orin FP16、batch=1 下测得 11.2ms vs 26.7ms（`Table 1, p.5`），引 P4，备用 P7。
- **`baseline`**：是否与同等参数量的结构化剪枝基线公平对比？→ `Table 1` 已同口径对齐 24M 参数与同训练轮数，ToyNet 仍高 +0.4pt（`§4.1, p.5`），引 P4，备用 P7。
- **`limitation`**：动态 batch>1 时加速比为何下降？→ 样本间活跃通道不对齐引入 1.9ms 掩码重排开销（`§5, p.7`），引 P6，备用 P7。

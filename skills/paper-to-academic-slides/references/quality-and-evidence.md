# 主线、证据与版式质量规则

## 1. 主线提取（S2 的骨架）
从 `paper_context.json` 依次回答四问，答案即页序：
1. **问题**：论文要解决什么、为什么现有方法不够（引言末段+abstract）。
2. **方法**：核心思路一句话 + 2–3 个关键组件（方法章节首段、框架图）。
3. **证据**：主结果表/图是哪几张、关键数字是什么（Table/Fig 题注索引）。
4. **限制**：作者自认局限与适用边界（discussion/limitations 段）。

页序骨架（可裁剪到 max_slides）：
`cover → 问题与挑战 → 方法总览 → 方法关键细节 → 实验设置 → 主结果(1–3页,每页挂1图/表) → 消融/分析 → 局限 → 结论`
- **局限页强约束**：若 `paper_index.md` 中 `limitations_pages` 非空且 `max_slides ≥ 7`，必须保留独立局限页。
- **裁剪优先级**：超限时优先砍背景综述与次要消融，必保封面、方法总览、主结果与结论。
- **受众/时长节奏**：严格遵循 `case.json`/`task.md` 中的受众与时长约束（如 10 分钟汇报约 8–10 页、单页要点更精炼；面向跨领域听众时首现术语加短注）。

**区分事实归属、事实层级与图类型**：
- 事实层级：主结论（abstract 声明的）> 支撑证据（表/图数字）> 作者观点/展望。PPT 上主张句只允许前两层；观点句必须带 "作者认为/作者指出"。
- **归属严格分离**：引用前人/基线数据时必须显式标出基线名或作者，严禁把他人结果当本文结论。
- **示意图声明**：方法框架图、流程图等非实验结果图，必须在页面图注/要点或 `notes` 中显式注明“示意图，非实验数据”。

## 2. 页面信息密度
- 一页一主张；bullets 3–6 条、每条 ≤22 词（中文 ≤30 字），层级 ≤2。
- 数字进入 bullets 时连单位一起搬：`89.1%`、`41 ms`、`+12.3`；**禁止四舍五入改写或换算单位**。
- 长句改写规则：删修饰、留主干与数字，但**不改限定词**（如 "仅在 ImageNet 上" 不能丢）。
- 同页图片 ≤2 张；大表优先引用表号+抄 2–3 行关键行，不整表截图。

## 3. 讲稿（notes）写法
每页 60–150 字，三选三：
- **过渡**：从上一页到本页的逻辑桥（"看完整体框架，现在深入第一点…"）。
- **强调**：页面上最该被记住的 1 个数字/结论 + 它成立的前提条件。
- **追问弹药**：预判一个提问，指出论文中的补充证据（章节号/附录表）。
禁止：逐条朗读 bullets；引入论文不存在的说法。

## 4. 模板与版式合规
- 内容只写进模板占位符；**不添加覆盖母版装饰的全幅矩形/背景色块**。
- 模板双模式：
  - `layouts` 模式（纯模板）：自动清空模板样例页，保留母版/配色/页脚并按最佳版式（图文/表文优先 Two Content）重建；
  - `reuse` 模式（起始 deck 原地适配）：原地保留页面样式并清理旧残留图/表/文本框。
- `build_deck.py` 自动行为：内容页标题优先在 28→22pt 区间单行拟合（防孤字换行），超长再双行自适应；封面副标题自动去项目符号圆点；正文 18→16→14→12→11pt 自适应并支持内联 `**关键词/数值**` 原生加粗；≥5 列宽表或横幅架构图（宽高比 ≥2.2）在要点 ≤3 条时自动切**上文下宽**布局；原生表 `Ours/本文` 行自动加粗；支持可选居中图注 `image_caption`；4:3-on-16:9 占位符自适应；深色背景自动保色并切换浅灰证据行；证据行 10pt 固定底部左。
- 图片按占位符或右侧半栏等比完整放入（单图 top-bias 防下沉），绝不拉伸变形或裁切坐标轴。
- 页脚/页码/Logo 由模板自带，脚本不触碰；若模板占位符缺失自动落 textbox 并在 `deck_build_report.json` 记 warnings。

## 5. 可核验性交付（评分硬指标）
- `evidence_map`（`result.json` + 独立 `evidence_map.json` / `evidence_map.md`）：每页 claim + paper_refs + quote + slide_line + 自动核验状态，由 `finalize_output.py` 自动汇总。
- 渲染与复现链路：PPTX（可编辑源）→ PDF（导出件）→ PNG（100 DPI 逐页预览），三者页数一致，且 `render_record` 记录 `repro_command`、输入/输出 SHA-256 哈希、工具版本与 PDF 字体审计。
- 版面检查报告 `layout_report.json` 与六要素审计 `six_element_audit` 随 `result.json` 输出；fail 必须清零后交付。

## 6. 字体与换机安全
- **模板模式**：绝不覆写母版主题字体；启动时经 `fc-list` 审计模板字体是否在本机安装，缺失时自动启用 `1.08x` 字符宽度安全补偿并在 `render_record.font_audit` 如实记录。
- **空白模式**：自动绑定本机 `fc-list` 已安装的 Latin/CJK 安全字体（如 Liberation Sans / Noto Sans CJK），确保正文、表格、KPI 卡、页脚与原生图表导出 PDF 时零字体替换漂移。

## 7. 与裸跑 baseline 的差异自证（增益来源）
加载本 Skill 后相对不加载的对照差异，逐条可核查：
1. **结构**：baseline 常按论文段落顺序贴段 → Skill 强制主张句标题+主线骨架（cover/问题/方法/主结果/局限/结论）。
2. **证据**：baseline 页面无来源 → Skill 每页 evidence_refs（题注 id+页码+原文 quote）+ 页面证据行 + verify_evidence 交叉校验（题注存在性/quote 原文性/数字可溯）。
3. **模板**：baseline 常覆盖母版配色/自造版式 → Skill 只填占位符，layout 打分选最合适版式，报告 layouts_used。
4. **讲稿**：baseline 备注缺失或复读正文 → Skill notes 三件套（过渡/强调/追问弹药）+ 重复率检测（>60% 报警）。
5. **版面**：baseline 长文本溢出/缩成小字 → Skill 降号梯度 18→11pt + 几何检查（越界/溢出估计/重叠/表格）fail 清零。
6. **渲染**：baseline 只交 PPTX → Skill 交付 PPTX+PDF+逐页 PNG+页数一致性校验+pipeline 日志。

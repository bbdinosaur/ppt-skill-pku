# 模板继承与版式规则

## 铁律（对应评分：模板约束 + 导出渲染）

1. **母版只读**：任何情况下不修改 slide master、theme、layout。所有改动只发生在 slide 层。
2. **占位符优先**：文字放进版式自带的 title/body 占位符 → 自动继承模板字体、字号层级、
   项目符号、配色。构建脚本不给 run 设置 `font.name`（唯一豁免：无占位符时的兜底文本框，
   也不设字体名，继承主题字体）。
3. **图片不裁不拉**：`add_picture_fit` 等比缩放居中放入槽位，绝不 `insert_picture`（那会裁剪）。
   `aspect` 检查容差 2%。
4. **页脚/页码/日期**：占位符留在 layout 上不动，导出后自动显示。检查器忽略这些区域。
5. **字号下限**：正文 ≥12pt（收缩下限），来源行/图注 ≥10pt。小于阈值会被告警。
6. **版式选择**：`layout_hint` 由 `pick_layout` 按名称关键词 + 占位符结构打分匹配模板真实
   版式；模板没有两栏版式时自动降级为"单栏占位符 + 右侧文本框"并在 plan 里注明。

## 文字防溢出

- 每条 bullet ≤2 行（约 ≤40 个全角字符 / ≤80 个拉丁字符）；要点 ≤6 条/页。
- `shrink_body_to_fit` 会在估高超出时按 1pt 步进收缩到 12pt 下限；再不够就该拆页，
  而不是继续压字号。
- 标题主张化：一行放得下（≤22 全角字符）；放不下就精简标题而不是缩字号。

## 版式内容分配

| 页型 | 布局 |
|---|---|
| 标题页 | title 版式，副标题=作者/场合/日期 |
| 图结果页 | bullets 占位符压到左侧 45%，图占右侧 50%，图注在图下 |
| 表结果页 | 同上，表格替代图 |
| 两栏对比 | two_content 版式（无则自动降级） |
| 来源行 | 内容区底部 10.5pt 斜体，逐页列出 ref+locator |

## 视觉自检（本地/支持读图的运行时）

```bash
soffice --headless --convert-to pdf presentation.pptx   # 或 export_preview.py
pdftoppm -png -r 110 presentation.pdf previews/slide
```
逐页看：零重叠、零越界、无截断、图注与图对齐、来源行不与页脚打架。发现一处修一处后重跑 check。
